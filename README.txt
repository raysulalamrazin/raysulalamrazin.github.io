Razin Portfolio - Redesigned

This version uses a dark navy and gold academic portfolio style inspired by the screenshots you shared, adapted for a nursing student.

Included:
- index.html
- assets/profile.png
- assets/certificates/ (5 certificate PDFs)

Publish:
1. Extract the ZIP.
2. Upload index.html and the assets folder contents to the root of:
   https://github.com/raysulalamrazin/raysulalamrazin.github.io
3. Commit changes, then check https://raysulalamrazin.github.io/

Note: The old CV button has been replaced by View Certificates because no CV PDF was supplied.
Two certificate names were unreadable, so those cards are labeled Additional Certificate.
